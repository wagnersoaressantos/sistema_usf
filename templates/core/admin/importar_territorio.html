{# Instruções #}

Como exportar o arquivo do e-SUS:

1. Acesse e-SUS → Relatórios → Acompanhamento do Território

2. Selecione a micro-área desejada (ou todas)

3. Exporte em CSV

4. Importe uma micro-área por vez ou todas juntas

{# Aviso #}

⚠️ O que acontece ao importar:

· Logradouros novos são criados automaticamente

· Pacientes encontrados pelo CPF/CNS têm o vínculo familiar atualizado

· Uma família é criada para cada responsável encontrado

· Cidadãos não encontrados no cadastro são contabilizados mas ignorados
